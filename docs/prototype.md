# Проверка интерактивности до разработки основного интерфейса

Запуск: `.venv/bin/python -m uvicorn scripts.prototype:app --port 8081`.
Тест в браузере Playwright выполнен 29.10.2026. Микротаблица синтетическая и предназначена только для проверки технологии, основной продукт использует архив ТЗ в PostgreSQL.

Фактически подтверждено: 8 SVG hit targets; точный тултип «Янв · План: 100,00 ₽»; выключение «План» оставляет 0 plan targets; фильтр уменьшает факт 90→45; выделение области отправляет новые пределы осей и получает новый SVG; сброс даёт zoom=null; при ширине окна 420 px тултип «Янв · Факт: 45,00 ₽» остаётся точным.

Реализация: Python задаёт gid каждому Matplotlib artist и экспортирует SVG + точные значения + координаты области осей. JS использует SVG getScreenCTM().inverse() для пересчёта pointer coordinates после resize. Zoom передаёт валидируемые xlim/ylim рендереру, серии выключаются через hidden в ChartSpec. Все графические примитивы и оси рендерит Matplotlib, Seaborn задаёт палитры и heatmap. Не используется автоматическое предположение об интерактивности SVG.

Синхронное обновление фильтров в продукте выполняется одним API-ответом с новой таблицей/KPI/графиками. Частые события debounce, AbortController и номер запроса защищают UI; revision предотвращает потерю серверных изменений. Графики имеют независимый zoom; изменение общих фильтров сбрасывает масштабы.
