# MY — чат и интерактивные дашборды

Запуск из корня: `./scripts/start_local.sh`. Адрес http://127.0.0.1:8080.

Границу между чатом и правой областью можно перетаскивать мышью; выбранная ширина сохраняется в браузере. Двойной щелчок возвращает исходный размер. При фокусе на границе доступны стрелки, Home/End и Enter для сброса; Escape отменяет текущий жест. На узких окнах используются прежние вкладки переписки и рабочей области.

На компьютере слева — переписка шириной 320–400 px, справа — **графики и таблица выбранного дашборда**. Вкладка «Графики» показывает до четырёх интерактивных Plotly-графиков со всеми настройками; «Таблица и расчёты» — актуальные строки, страницы и вычисления из того же сохранённого контекста. Запрос таблицы или правка вычислений открывает табличный режим автоматически, чат остаётся слева. Кнопки в ответе открывают соответствующий результат справа. Список над панелью переключает анализы этого чата. На широком контейнере графики расположены 2×2, на узком — в одну колонку. Доступны tooltip с точными числами, серии, масштаб, значения и общие фильтры. Состояние изменяется без вызова ИИ.

Название чата над перепиской открывает список: поиск, переход, переименование текущего чата. «＋» создаёт новый. Прежние сообщения сохранены в «Основном чате». Чаты изолируют сообщения, таблицы, формулы, фильтры, дашборды/версии, черновики и фоновые запросы. Собственные шаблоны запросов общие для владельца. Имена новых чатов берутся из первого запроса; ручное имя не заменяется. Переход использует отдельный документ и явный X-Conversation-ID во всех API-запросах, включая вложения и файлы; чужой ID не даёт доступ. Старые API без заголовка работают с основным чатом.

Старые дашборды доступны для выбора и изменения фильтров во время нового анализа. Настройки карточек имеют отдельную ревизию: изменение другой карточки или новый ответ не мешают автосохранению. Новый ответ сохраняет параллельные правки старых сообщений; если одновременно менялся исходный рабочий дашборд, результат ИИ становится отдельной записью. Ручной выбор панели во время анализа сохраняется после его завершения.

Кеш в IndexedDB восстанавливает последнюю переписку/дашборд до ответа API и сразу показывает уже открытые варианты фильтров, включая KPI и каскадный список точек. До проверки сервера восстановленные настройки доступны для просмотра; автосохранение подтверждается только сервером. Новый вариант сначала пересчитывается, затем кешируется. На сервере SQLite содержит до 12 готовых вариантов на карточку / 48 на контекст, браузер — до 50 записей на чат. Ключи учитывают владельца, чат, сообщение, фактическое содержимое исходных данных, формулы, конфигурацию и размер рендера. Обновление источника, формулы или движка меняет ключ. HTTP-ответ карточки не содержит всю переписку; API `/api/cards/{id}` и `/api/cards/{id}/edit` передаёт только выбранный дашборд и его ревизию.

Исходная таблица и вычисленный снимок сохраняются общими сжатыми блоками, а состояния сессий, карточек и библиотеки ссылаются на них. Прежний встроенный формат читается без миграции; новая запись нормализуется при сохранении. История версий, CSV/Excel/HTML/PNG, копирование и восстановление продолжают использовать полные данные через Store. Сохранение ревизии, карточки, библиотеки и ссылок на данные атомарно; ошибочная запись не меняет последнее сохранение.

Меньше 1100 px области переключаются вкладками «Переписка» / «Дашборд». На телефоне кнопка «Фильтры и настройки» раскрывает параметры прямо в панели, текущие регион и период видны всегда. KPI и первый график доступны без прокрутки всех фильтров. Панели имеют независимую прокрутку; выбор дашборда и позиции восстанавливаются при возвращении в чат. Фоновый анализ продолжается в исходном чате. «Новый анализ» справа очищает только выбранную рабочую область; переписка, библиотека и прежние дашборды остаются. Таблица, вычисления, копия/название, экспорт, версии и публикация доступны справа.

Одна точка за один месяц показывается столбиком с точной величиной, подписью месяца и торговой точки. Полностью пустой выбор показывает отсутствие данных. В поле торговых точек доступны поиск и несколько галочек; список не закрывается после выбора, выбранные точки и поиск сохраняются при пересчёте.

Графики используют общую палитру и шрифт; известные имена полей и подписи вычисляемых колонок отображаются по-русски, кварталы — «I кв. 2025». Зум: выделение мышью, кнопки «+ / −», клавиши `+`, `−`, `0` при фокусе на графике. На телефоне кнопки масштаба ≥44×44 px. По умолчанию зум независим; «Связать масштаб по времени» синхронизирует временную область графиков с x=period. Ось Y у каждого своя, KPI не пересчитываются, категории и круговые диаграммы не затрагиваются. Временная полоса обработки не уменьшает рендер остальных диаграмм. Общие фильтры обновляют все графики и KPI и очищают прежние области масштаба. Сохранённый снимок восстанавливает фильтры, серии, масштаб, связь, таблицу, расчёты и KPI.

Непосредственно под графиками находится «Краткий итог»: факт/план, выполнение, отклонение, динамика и активные объекты. Значения взяты из KPI той же карточки и учитывают её период, регион и остальные фильтры. Итог обновляется без дополнительного вызова модели; зум не меняет итоговые суммы. Пустой выбор, отсутствующий/нулевой план и недоступная база сравнения обозначаются явно. При возврате из библиотеки итог восстанавливается по сохранённым данным. Полный текст ответа ИИ остаётся слева в переписке.

Поиск значений доступен также в регионе, разрезе, шаге времени и TOP-N. Регион и точки поддерживают несколько галочек; остальные параметры — один вариант. В «Данных» тот же компонент используется для регионов, точек, продуктов и клиентов. Регистр и ё/е не учитываются, несколько слов сопоставляются независимо от порядка. Видны число совпадений и отсутствие результатов; поиск только сужает список и не меняет выбранный фильтр. Ограничение первых 500 вариантов убрано. Компонент сохраняет DOM, запрос, выбранные значения, открытое состояние, фокус и прокрутку при обновлении. Escape возвращает фокус полю, стрелки и Space/Enter работают с найденными вариантами.

Регион → торговые точки образуют каскад: доступны только точки выбранных регионов, без региона — все точки загруженного набора. Несколько регионов объединяют списки. При смене региона прежний выбор точек сбрасывается; зависимый список до ответа сервера показывает «Обновляю список…», скрывает устаревшие варианты и блокирует выбор. Поиск при этом остаётся доступен и сохраняется. Подсказка показывает область и число доступных точек. У всех графиков и KPI одного дашборда общие фильтры и один ответ сервера; при ошибке элементы управления возвращаются к последнему применённому выбору.

Четыре переключателя всегда доступны в карточке: «Разрез» (регионы/точки/продукты), «Метрика» (выручка/скидки/сделки/выполнение), «По времени» (месяц/квартал/год), «Вид» (абсолютные значения/доли/динамика). Разрез обновляет сравнение плана и факта и строки тепловой карты; временная ось остаётся временной. Метрика и вид также доступны открыто во вкладке «Данные». Все варианты поддерживают поиск, сохранение DOM/фокуса/прокрутки и восстановление из снимка.

Проценты означают долю всего выбранного объёма до TOP-N. Выполнение плана уже является процентной метрикой и считается от сумм. Динамика временных графиков — изменение к предыдущему календарному периоду; сравнение объектов и категорий — последний период относительно предыдущего. Для выполнения показываются процентные пункты. База берётся из загруженного снимка, текущие значения сохраняют фильтр дат; при отсутствующей/нулевой базе значение не определено. Скидки и сделки имеют факт без выдуманного плана. KPI сохраняют итоги диапазона в единицах метрики — это поясняется над графиками.

На коротком широком окне уплотняются служебные строки. Длинный рейтинг прокручивается внутри своей диаграммы, сохраняя читаемые подписи и место для остальных графиков. На телефоне — обычная вертикальная колонка.

Прогресс находится над полем ввода: текущий этап, выполненные шаги, полученные строки, число собранных графиков. У анализа неизвестное число шагов, поэтому этот этап имеет неопределённую полосу; при сборке известны реальные N/M. Фоновые задачи имеют owner-scoped API, idempotency request_id и восстановление наблюдения после обновления страницы. Ввод и очередь сообщений остаются доступны.

Вторая вкладка «Данные» содержит таблицу, формулы, типы/пропуски, фильтры, сохранённые снимки, экспорт и отладку ReAct. После выбора дашборда для работы здесь его таблица; без явного выбора — таблица последнего запроса. Каждая карточка в переписке хранит собственные исходные данные и параметры. Предыдущий дашборд открывается справа по кнопке сообщения; его выбор явно переключает рабочий контекст. Правки относятся только к выбранному снимку.

В шапке чата «Мои дашборды» открывает список с названием, исходным запросом, временем создания/изменения, поиском, сортировкой, переименованием и удалением. «Продолжить работу» восстанавливает данные, формулы, фильтры, графики, скрытые серии, масштаб и KPI без источника или ИИ и выбирает дашборд для дальнейшего диалога. То же действие в старой карточке выбирает её без нового сообщения. Имя выбранного дашборда остаётся над полем ввода; рядом «Таблица и расчёты», «Создать копию» и «Новый анализ». Запросы ИИ дорабатывают эту же запись; копия выбирается отдельно, а новый анализ снимает выбор, сохраняя переписку и библиотеку. Список и выбранный контекст восстанавливаются после перезапуска в том же браузере.

Фильтры, метрика, период, вид, серии, масштаб, формулы и обновлённые данные автоматически записываются в текущий дашборд. Запись обновляет тот же ID без дубликатов, сохраняя имя и исходный запрос. Статус фильтра: «Сохраняю…» → «Автосохранено» после подтверждения сервера. «Название и копия» позволяет переименовать текущий дашборд или создать отдельную копию. Запись текущей сессии и автосохранённого снимка происходит в одной транзакции: ошибка или конфликт версии не повреждают последнюю сохранённую версию. Без выбранного дашборда новый ответ ИИ с графиками сохраняется отдельно; обычные текстовые сообщения не засоряют список.

«Действия» в карточке открывает скачивание PNG/HTML и таблицы CSV/Excel. Экспорт учитывает фильтры и вычисления именно выбранной карточки. HTML автономный: графики с тултипами, сериями и масштабом, KPI и краткий итог открываются без сервера; значения фильтров фиксированы. Excel содержит данные, определения вычислений и параметры.

Там же «История версий» показывает дату, вид изменения, период, регион и число вычислений. «Восстановить» возвращает полный снимок этой карточки, не меняя выбранный контекст другой карточки. Откат записывается новой версией, более поздние версии остаются. Для старых сохранений исходной является текущая версия на момент внедрения истории.

«Создать ссылку» публикует снимок только для просмотра: графики и KPI без редактора, чата и исходной таблицы. Можно копировать ссылку, явно обновить снимок и отозвать доступ. Удаление дашборда отзывает ссылку. Публикации обслуживает отдельный `MY.public:app`, а не основной редактор. Локальный запуск временного адреса — `uv run python scripts/start_public.py`; для постоянного домена — HTTPS origin в `RPA_PUBLIC_BASE_URL`. Временная ссылка зависит от запущенного сервиса на Mac и может измениться при переподключении.

Черновик ввода сохраняется локально и на сервере, отдельно по выбранному дашборду и общему диалогу. Перезагрузка восстанавливает текст, в том числе локальную копию после работы без сети. Очередь неотправленных запросов сохраняется с возможностью повтора. «Шаблоны запросов» у ввода вставляет типовой или собственный запрос для редактирования; готовые три шаблона нельзя удалить, собственные можно сохранить, изменить и удалить.

Сетка страницы занимает высоту окна, история прокручивается отдельно от composer. Размеры адаптируются через Grid, контейнерные запросы, fluid widths и 100dvh/visualViewport. Таблица прокручивается внутри своей области; страница не расширяется по горизонтали. Пользовательская разметка проходит через безопасный DOM-renderer; SVG поступает только от Matplotlib.

Подготовка БД/модели — [общая инструкция](../README.md). Telegram-код, запускатель, авторизация и зависимость удалены.

Визуальная оболочка — максимально простой белый чат: небольшая навигация, вопрос/ответ и поле ввода. При получении ответа с графиками виден дашборд: регион, точки, даты, разрез и метрика открыты над графиками. «Настройки графиков» раскрывают группировку, вид и TOP-N в той же карточке, текущие значения видны в свёрнутой строке. Сверху четыре основных KPI и компактная строка активности и динамики; ниже сетка до четырёх графиков и краткий итог; полный текст ИИ остаётся в переписке слева. Высота диаграмм учитывает размер окна, один график использует всю ширину. После ручного изменения фильтров комментарий ИИ помечен как относящийся к первоначальному выбору; показатели и графики пересчитываются сразу.

Обновление фильтра сохраняет DOM параметров и сообщения: раскрытия, фокус, вертикальная/горизонтальная прокрутка не сбрасываются. Быстрые последовательные изменения фильтров применяются через общую очередь; последним остаётся последний выбор. Тепловые карты используют две оси и агрегированные значения, контрастную шкалу и числовые подписи. При большом числе точек показываются TOP-N с пояснением, на узком экране матрица прокручивается внутри графика.

Сохранённый конфликт региона и точек исправляется до передачи контекста модели и при обновлении интерфейса: несовместимые точки убираются, пояснение видно над показателями. Реальные пустые выборки остаются пустыми. Точные значения графиков доступны полностью, без ограничения 500 строк. На телефоне фильтры в две колонки, диаграммы — в одну; широкая матрица прокручивается внутри своей области.

По просьбе показать таблицу справа автоматически открывается «Таблица и расчёты» с заголовками, строками, счётчиком и страницами по 25/50/100 строк. Добавление или изменение вычисления также открывает актуальную таблицу. Формулы можно добавить, изменить, удалить или отменить; правки относятся к выбранному анализу. Страницы, DOM и внутренняя прокрутка сохраняются между табличной и графической вкладками; режим панели восстанавливается после reload отдельно для каждого чата. CSV остаётся вложением. Исходный снимок табличного ответа хранится неизменным; таблица редактируемой карточки показывает её текущее состояние без нового запроса к ИИ.

Сравнения по точкам/регионам, рейтинги и динамика по умолчанию показываются графиками — даже для «выдай выручку точек за 2026» без слова «график». Таблица остаётся формой явного запроса таблицы. Финал без реальных графиков для intent=chart/dashboard возвращается в ReAct с ошибкой протокола; Markdown-таблица без структурированного результата не считается завершённым intent=table. fetch_data(all_time=true) определяет реальные границы дат в pandas и выбирает весь период, в том числе после пустого года. Ограниченная доступность продаж за часть года видна над графиком.

KPI-карточки: общий план, общий факт, выполнение плана, отклонение в единицах метрики и процентах, активные клиенты / точки / продукты, динамика факта к предыдущему сопоставимому диапазону. Счётчики учитывают реальные уникальные ID с продажами; плановые строки и условный клиент «Не распределён» не увеличивают активность. Клиентская принадлежность сохраняется отдельно от месячных итогов, план по клиентам не распределяется. Для выполнения динамика в п.п., верхние план/факт — денежные. Отсутствующая/нулевая база обозначена явно, без вымышленного 0%. Общие фильтры меняют все карточки и графики; карточки сохраняют DOM, точные значения доступны в title и aria-label. Широкая/средняя/узкая сетка — 8/4/2 колонки.

Старые снимки можно обогатить клиентами: остановить MY, запустить `uv run python -m scripts.backfill_activity` для проверки и затем с `--apply`. Перед записью создаётся резервная копия SQLite, источник должен воспроизвести сумму и число сделок каждой замороженной ячейки; изменения продаж не перезаписываются. Полная база прошлого периода должна уже находиться в снимке.

У каждого сообщения с дашбордом — отдельный замороженный контекст в SQLite (владелец + ID сообщения). Запросы изменения передают message_id, очереди быстрых фильтров разделены по карточкам. Все сохранения остаются атомарными с сессией; после перезапуска можно продолжать менять предыдущую карточку. «Название и копия» также относится к той карточке, где нажата кнопка. Старые ответы без снимка получают явное пояснение; они не подменяются свежими данными источника.
