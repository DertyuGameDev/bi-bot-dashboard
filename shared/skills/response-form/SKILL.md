# Выбор формы ответа

Когда применять: Любой аналитический запрос.

Входные данные: Запрос, текущая таблица и диаграммы.

Последовательность: Определи управленческий вопрос. Для одного числа используй profile_table и текст. Для проверки строк — таблицу. Для сравнения одного разреза — один график. Запросы «выдай выручку точек за 2026», «покажи продажи по регионам», рейтинги и динамика означают интерактивный график по умолчанию, даже без слова «график». После такого вопроса «за всё время» сохраняет визуальную форму. Не заменяй график Markdown-таблицей. Для обзора динамики, структуры, рейтинга и выполнения — до 4 графиков. Сохраняй уже построенный результат при текстовом уточнении.

Инструменты: profile_table, create_chart, create_dashboard.

Ожидаемый результат: Обоснованный тип ответа без лишних графиков.

Ограничения: Не создавать дашборд на «каков общий факт?». Уточняй только неоднозначные метрики/периоды.

Пример: «Сколько продали?» → profile_table. «Обзор продаж» → create_dashboard.

Критерии проверки: Форма соответствует запросу; текстовые вопросы не меняют графики.

В MY результат визуального запроса — один интерактивный дашборд с максимум четырьмя графиками: кнопка в сообщении открывает полную панель справа. Не разбивай его на отдельные изображения. charts задаёт выбранные id, а не новые дубли. Для одной точки за один месяц допустим столбик: если пользователь просит график, покажи его с подписью и точной величиной. Для обычного вопроса о числе достаточно текста. Обычный текстовый вопрос не должен повторно показывать предыдущие графики. Экспорт — отдельный файл по запросу.

При просьбе показать таблицу выбирай table=true: кнопка в ответе открывает таблицу справа от чата, с заголовками, строками и страницами. Рядом доступны графики и вычисления того же сохранённого анализа; после изменения вычислений открывается актуальная таблица. CSV остаётся отдельным вложением. Не заменяй таблицу только ссылкой на файл или предложением перейти во вкладку «Данные».

Выручка по точкам: fetch_data с нужным годом (или all_time=true для всей истории) → apply_filters(dimension=outlet) → create_dashboard/create_chart с horizontal_bar source=ranking,y=[fact] и при необходимости динамикой source=period. Готовые id обязательно укажи в charts. Сравнение не считается завершённым одной текстовой таблицей. Если данных за год нет, ответь об этом текстом; после нового периода не используй старый пустой фильтр.
