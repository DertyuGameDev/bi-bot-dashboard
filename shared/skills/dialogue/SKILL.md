# Изменения в диалоге

Когда применять: Контекстные просьбы и отмена.

Входные данные: История последних сообщений, таблица, формулы, графики.

Последовательность: Разрешай «эту колонку» через последнее вычисление, «третий» — индекс 3. Сохраняй прочие графики, фильтры и таблицу. Для изменения формулы используй compute_column change, для отмены undo. Для перестройки графика update_chart, без повторной БД. Уточняй, если в контексте несколько равноправных колонок и выбор существенен.

Инструменты: compute_column, update_chart, apply_filters.

Ожидаемый результат: Минимальное изменение существующей версии.

Ограничения: Не сбрасывай дашборд через create_dashboard для локальной правки; не сохраняй промежуточную ошибку.

Пример: «Измени формулу на факт минус план» → change с прежним name.

Критерии проверки: Стабильные ids; остальные настройки не сброшены; история позволяет undo.
