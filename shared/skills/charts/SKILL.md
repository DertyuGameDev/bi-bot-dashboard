# Выбор и построение графика

Когда применять: Запрос графика или изменение визуализации.

Входные данные: Профиль таблицы, вопрос, ChartSpec.

Последовательность: Используй grouped_bar для план/факт, line для времени, horizontal_bar для TOP-N, stacked_bar для суммы частей, scatter только numeric x/y, histogram для распределения, heatmap для матрицы, donut для 2–7 неотрицательных категорий. source period/structure/ranking/table. Интерактивные графики строит Plotly, единый стиль и палитры задаёт Seaborn. SVG/PNG для статического экспорта строит Matplotlib/Seaborn из той же агрегированной таблицы. Задавай русские title, xlabel/ylabel, number_format. Длинные названия — горизонтальные бары. Не меняй стабильный id.

Инструменты: create_chart, update_chart, validate_result.

Ожидаемый результат: Валидная ChartSpec и Plotly figure для интерактивного виджета; SVG остаётся статическим представлением.

Ограничения: Не подменяй интерактивный Plotly-виджет картинкой или отдельным приложением. Для table source X и Y должны существовать.

Пример: «Перестрой третий по выполнению» → update_chart(index=3, changes={sort:completion}).

Критерии проверки: Оси и типы совместимы, title читаем, tooltip содержит точное число.

Одна точка за один месяц — допустимый столбик с точной величиной и подписью месяца/точки. Создавай запрошенный график, не расширяя период ради числа наблюдений. Линия или heatmap с одним значением автоматически отображаются столбиком. В MY все выбранные графики объединяются в одну карточку, максимум четыре.

Для круговой диаграммы доступны точные tooltip, выделение сектора кликом и выбор сектора с клавиатуры. Геометрического зума у неё нет; пользователь выбрал выделение сектора.

Для вычисляемой серии используй понятный русский label рецепта: он попадает в легенду, ось и точные тултипы. Известные технические имена полей нормализуются, кварталы отображаются как «I кв. 2025», исходные ключи периодов не меняются. Общий шрифт и палитру задаёт renderer; отдельную тему для каждого графика не создавай.

Тепловая карта: x=period, group=outlet (или другой разрез), y=[fact]. Не передавай сырые повторяющиеся строки как одномерную карту; группировка делает матрицу. В интерфейсе TOP-N ограничивает число строк с явным пояснением. Хотя бы одна серия остаётся видимой.
