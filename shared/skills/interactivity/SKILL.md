# Интерактивность

Когда применять: Фильтры, метрики, разрезы и масштаб.

Входные данные: Доступные значения, Filters, ChartSpec.

Последовательность: Фильтры применяются ко всей таблице, KPI и диаграммам. Regions/outlets/products — multi-select с поиском. Region сужает outlets. Даты сопоставляются с месячным планом. TOP-N ограничивает рейтинг и строки тепловой карты с явной подписью; KPI считают всю выбранную таблицу. Для TOP-N не фиксируй outlets: список должен обновляться вместе с регионом. Несовместимые сохранённые точки убираются с пояснением filter_notice. dimension region/outlet/product/client, metric amount/discount/deals/completion (quantity — прежний режим количества товара с одной единицей), granularity month/quarter/year, value_mode absolute/percent/dynamics. Обычные UI-события обрабатывает API без модели. zoom и hidden принадлежат отдельному ChartSpec.

Инструменты: apply_filters, update_chart, set_sync_zoom.

Ожидаемый результат: Единое подтверждённое состояние и согласованные графики.

Зум по умолчанию независим для каждого графика и не меняет данные/KPI. В MY Plotly нативно обрабатывает колесо/трекпад, выделение области и перемещение. Кнопки «+ / −», «Сброс», «Перемещение» и клавиши `+`, `−`, `0` доступны на графиках с осями. Оси/подписи пересчитываются сразу в браузере; сервер только сохраняет область с объединением частых жестов. В круговой диаграмме вместо геометрического зума — выделение сектора кликом или выбором в списке и точный tooltip. Общий фильтр очищает прежний zoom у всех графиков перед пересчётом. «Связать масштаб по времени» / set_sync_zoom(enabled=true) связывает горизонтальную область временных графиков по календарным периодам. Вертикальные области остаются отдельными; круговые диаграммы и категориальные рейтинги не меняются. Нужны минимум два графика с x=period. Состояние связи, масштаба и серий сохраняется в снимке; клики не требуют модели.

Ограничения: Не смешивать физические единицы quantity. Не выдавать план скидок или клиентов без источника.

Пример: «Покажи только Северо-Запад» → regions=[Северо-Западный].

Критерии проверки: KPI совпадают с отфильтрованной таблицей; устаревший ответ не затирает новый.

Настройки каждого сообщения обновляются отдельной ревизией карточки, без модели/источника и без пересылки всей переписки. Во время нового анализа можно выбирать и редактировать прежние дашборды. Кешированные варианты фильтров, KPI, графики и каскадные списки показываются сразу; подтверждение автосохранения приходит с сервера. Новое сочетание параметров сначала пересчитывается. Кеш учитывает фактические данные, формулы, конфигурацию и размер рендера. При параллельной правке исходного рабочего дашборда результат ИИ сохраняется отдельно, а прежние изменения остаются.

MY: результат сообщения — единый дашборд до четырёх интерактивных SVG-графиков. В переписке слева его компактная кнопка, полный редактируемый дашборд справа. Выбор карточки/списка выбирает контекст дальнейших сообщений. Tooltip, серии, масштаб, значения и общие фильтры работают без модели. Раскладка реагирует на ширину правой панели: две колонки или одна. На узком окне — вкладки «Переписка» / «Дашборд», на телефоне фильтры раскрываются в панели, область выбора видна в свёрнутом виде. Основные фильтры на компьютере открыты над графиками: регион, точки, даты, разрез и метрика. Группировка, вид и TOP-N в строке «Настройки графиков». Устаревший выбор региона и точек согласуется до контекста модели. Полный текст ИИ остаётся в чате и помечается при смене фильтров. Для одного значения показывается настоящий столбик. Точки выбираются несколькими галочками с поиском; список сохраняется при пересчёте. Telegram удалён.

Проценты — доли выбранного итога, а completion — взвешенное выполнение sum(fact)/sum(plan)*100. Динамика сравнивает предыдущий календарный период month/quarter/year; используй загруженную базу, при её отсутствии/нуле значение не определено. Для completion динамика в п.п. Все переключатели доступны в карточке без ИИ и сохраняются в снимке. Сравнение по dimension показывает план/факт, тепловая карта меняет строки на выбранный разрез.

Каждая карточка в переписке редактируется независимо, в том числе предыдущая после следующего ответа. Изменения UI используют замороженные данные выбранного сообщения и не меняют следующие карточки. Если пользователь явно выбрал «Продолжить работу», context.workspace указывает дашборд для запросов ИИ и вкладки «Данные»; его собственные правки обновляют этот контекст. Фильтры другой карточки не переключают выбранный workspace. Не вызывай модель ради кликов фильтров. Четыре основных KPI выделены, остальные показатели компактнее; все точные значения остаются доступны.

Справа от чата расположены вкладки «Графики» и «Таблица и расчёты» одного выбранного анализа. table=true и правка вычисляемых колонок открывают табличный режим автоматически. Таблица показывает актуальные фильтры и формулы своей карточки, а её чтение и ручное редактирование не переключают глобальный контекст к другой карточке. В переписке остаются компактные кнопки результата; не проси уходить из чата во вкладку «Данные» для просмотра таблицы.
