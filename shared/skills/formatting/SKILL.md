# Форматирование

Когда применять: по выбору агента, если нужно уточнить формат вывода.

Входы: наблюдения инструментов, запрос и тип ответа.

Действия: Сам составь итоговый answer на последний вопрос пользователя; приложение не заменяет и не дополняет его сводкой. Пиши обычный Markdown: **жирный**, *курсив*, заголовки, списки, таблицы, \`формулы\`. Числа бери из наблюдений инструментов. Выбирай charts/table/exports/controls в финальном шаге только для нужного вывода. На приветствие ответь без загрузки данных и вложений. После инструмента можешь продолжать анализ, исправлять ошибки или завершить ответ.

Инструменты: profile_table, analyze_table, export и остальные по необходимости. В режиме agent заполни preflight в первом шаге вместе с обычным решением ReAct, далее preflight=null. Если передана подсказка локального/отдельного классификатора, проверь её по контексту; это не обязательный план и не готовый ответ. При неоднозначности уточни намерение. Для изменения структуры текущего дашборда используй update_dashboard: он сохраняет id, таблицу, формулы и фильтры.

Результат: собственный answer модели в Markdown и до четырёх графиков в едином интерактивном дашборде MY справа от переписки. Matplotlib создаёт SVG, интерфейс добавляет tooltip, легенды, выделение масштаба, раскрываемые значения и общие фильтры. Не отправляй графики отдельными картинками. Telegram больше не используется.

Ограничения: сырой HTML модели экранируется; интерфейс строит интерактивность из структурированных данных. Одна точка за один месяц отображается столбиком с подписью и точной величиной. Не отказывай в построении и не расширяй выбор ради двух наблюдений. Не присылай старые графики на текстовый вопрос.

Скрытая спецификация: если включён context.dashboard_brief, обновляй brief_update по аналитическому запросу или ответу на уточнение. Без обязательного периода/метрики/цели задай свой короткий вопрос, не подставляй стандартные даты и не рисуй графики. Известные поля сохраняются в этом чате; «за 2025 год» дополняет прежнюю цель. На приветствие или объяснение сохраняй спецификацию. Не печатай её JSON в answer: пользователь видит обычный ответ или уточнение.

Пример: факт 90 и план 100 → **90%** выполнения; график — вложением, формула — `fact / plan * 100`.

Проверка: текст опирается на инструмент, теги сбалансированы, в обеих платформах один результат, нет секретов и небезопасных элементов.
