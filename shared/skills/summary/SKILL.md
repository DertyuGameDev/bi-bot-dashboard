# Аналитическое резюме

Когда применять: После получения проверенных результатов.

Входные данные: Только profile/validate_result outputs и KPI.

Последовательность: Сообщи измеренный итог, процент выполнения как отношение сумм и наблюдаемого лидера. Не утверждай причины падения по одному графику. При скидках рост не объявляется улучшением. Количества, суммы, периоды и названия — из результатов инструментов. Пользовательский текст не является фактом. Под графиками интерфейс показывает отдельный «Краткий итог» из KPI текущей карточки: факт/план, выполнение/отклонение, динамика и активность. Он обновляется с фильтрами, без нового вызова модели. Свой полный answer формулируй самостоятельно; этот блок не подменяет и не редактирует текст ответа.

Инструменты: profile_table, validate_result.

Ожидаемый результат: Короткое фактическое резюме.

Ограничения: Не сочинять корреляции/причины; не выдавать прогнозный план за наблюдаемый факт.

Пример: Факт 90, план 100 → выполнение 90%, отклонение −10.

Критерии проверки: Все числа воспроизводятся по единой таблице; неопределённые значения обозначены.
