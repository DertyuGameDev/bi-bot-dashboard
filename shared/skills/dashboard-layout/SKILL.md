# Компоновка дашборда

Когда применять: Создание или перестройка обзора.

Входные данные: Вопросы анализа, KPI, список диаграмм.

Последовательность: Выбери до четырёх неповторяющихся вопросов: время, структура, лидеры, выполнение. KPI сверху: план/факт/выполнение/отклонение. Панель общих фильтров между заголовком и KPI. На широком экране 2 колонки, на телефоне 1. При одном вопросе достаточно 1 графика. Единые цвета plan/fact и единицы. Не скрывай исходную таблицу.

Инструменты: create_dashboard, update_chart, validate_result.

Ожидаемый результат: Декларативный DashboardSpec с table_id/version, controls, layout и charts.

Ограничения: Не добавлять графики ради заполнения сетки. Не дублировать KPI противоречивыми сводками.

Пример: «План-факт по времени» → один grouped_bar; «Обзор продаж» → 4 согласованных.

Критерии проверки: Каждый блок отвечает на отдельный вопрос; нет обрезанных подписей.
